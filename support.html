Questions fréquentes

  • Aucune donnée ? Autorise Apple Santé dans Réglages iOS › Santé › Accès aux données › BenHealth Pro, et porte ta Watch.
  • Effacer mes données : Réglages › Outils › Effacer toutes les données locales.
  • Coach IA : ajoute ta clé API dans Réglages › Coach IA.
  • Essayer sans Watch : Réglages › Outils › données de démo.

FAQ

  • No data? Allow Apple Health access in iOS Settings › Health › Data Access › BenHealth Pro and wear your Watch.
  • Erase my data: Settings › Tools › Erase all local data.
  • AI coach: add your API key in Settings › AI coach.
  • Try without a Watch: Settings › Tools › demo data.
